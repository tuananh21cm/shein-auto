Cookie 4Seller

Đa tài khoản — kéo file cookie export vào, hệ thống tự detect tài khoản (theo uid). Shop thuộc tài khoản nào worker tự dùng cookie tài khoản đó.

🔐 Tự đăng nhập khỏi paste cookie tay

Nhập email + mật khẩu 4Seller — hệ thống tự đăng nhập (giải captcha qua CapSolver) và lưu cookie. Tích "Nhớ…" thì cookie hết hạn sẽ tự login lại, khỏi làm gì.
📥
Kéo 1 hoặc NHIỀU file cookie (.json) thả vào đây
Mỗi file export từ Cookie-Editor của 1 tài khoản 4Seller — kéo 2 file của 2 tài khoản là tự tách 2 tài khoản. Cookie hết hạn? Kéo file cookie MỚI của tài khoản đó vào — hệ thống tự nhận theo uid và thay đè, KHÔNG cần xoá cái cũ. Hoặc .
